### Changed

- A library's mangled symbols are a function of its own path: relative to the workspace root, or to the entry's directory for a library outside the workspace, encoded injectively (`/` as `__`, any other non-identifier byte as `_xHH`, a directory library ending in `_`). Two libraries never share a name — two `util.hl` in different directories included — and neither import order, the build's other imports nor where the tree is checked out changes a library's symbols. Every library's symbols change except a single-file library named by its file name alone (`util.hl` beside the entry outside a workspace stays `util`); a mangled name a diagnostic prints today, as the bus dead-wiring warnings do, reads in the new form.
- Qualified bus subjects are resolved once, in the desugar sequence, before the check; the checker, the model and lowering read one rewritten program.
