- Every run of a host command (`hale habitat organism place|unplace`) is handed `HALE_DNA_HOST_RESERVED_BYTES`, the memory the habitat's own containers on that host may hold: the sum of their compose `mem_limit`s, read from the compose files the habitat wrote on its machine (over the person's login through a pointer). On the habitat's own machine it counts its memory, nerves, senses' store, forge and Grafana (which starts on demand); on any host, the organisms' allocations applied there; `0` when the habitat runs nothing there that declares a limit. `--plan` names it on a `reserve` line. A provider's node subtracts it from the memory it offers models, so a node placed on a host the habitat also runs on does not overcommit it.
