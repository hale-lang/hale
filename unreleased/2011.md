### Breaking
- `std::process::rss_bytes()` returns the process's current resident memory in bytes (`/proc/self/statm` on Linux, mach `task_info` on macOS), the number `hale_process_resident_memory_bytes` reports, and no longer its peak (`getrusage`'s `ru_maxrss`), which the spec documented. On macOS it was also 1024 times too large (GH #1906). Migration: use `std::process::peak_rss_bytes()` for the peak.

### Added
- `std::process::peak_rss_bytes() -> Int`: the process's peak resident memory in bytes, `ru_maxrss` in the platform's unit made bytes (bytes on macOS, KiB on Linux) (GH #1906).
