- A SIGINT / SIGTERM drain, or `main`'s `run()` returning, now stops every listener in the process. Each `std::http::Server` stops accepting, answers the requests it already accepted, and returns. A server on `main` or a pinned thread used to keep accepting, so a program that reads `self.draining` waited out the whole 5 s grace and died by the signal.
- An accept on the main thread now delivers what other threads publish to subscribers on main while it waits. A pinned locus's `std::log` line to a sink on main appeared only when the next request arrived, so on an idle server it never appeared.
