### Fixed

- `push` and `set` on a local record's `bounded[T; N]` list now store a value of the list's own, as a list a locus holds already did. Before, a local's list kept the very block it was handed, so `push(l.list, y); y.k = 2` changed `l.list[0]`, and a write through an element showed in the binding it came from (GH #1918). A literal, a call's result, or a local not used after the store is still kept without a copy. Anything another name still reaches is copied, and on a hot path `hale verify` reports that copy (`copy: a value another name reaches stored into a bounded list`).
