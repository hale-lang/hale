### Breaking: `std::api::Outcome` carries bytes

- `std::api::Outcome::Result` and `HandlerError` carry the codec's bytes (`Bytes`) instead of a `String`, and `HandlerError` carries a `std::api::ErrorClass` beside them (`Unclassed` until an error type's variants declare classes). A transport a program writes now matches `Result(b)` on `Bytes` (`std::str::from_bytes(b)` is a JSON codec's text) and `HandlerError(b, class)`. A protobuf body crosses the runtime interfaces as the message's own bytes, not base64 in a String.
