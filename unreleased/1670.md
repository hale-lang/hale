- **A server outlives `main`'s `run()`.** A program whose main locus has no `run()`, or whose `run()` returns while a server is live, keeps serving until SIGINT or SIGTERM: `main`'s `run()` returning no longer stops the process's listeners, which #1659 had it do (unreleased), so a main that only built its pinned children lost its HTTP listener at start.
