### Breaking
- `hale check` refuses, at the construct and with a way forward, every construct the compiler cannot lower yet (GH #1942): an unsized `[T]` or a non-literal array length, a generic fn call that binds an array, tuple, `bounded` or fn type, a generic locus method, `[]` outside a typed `let`, a nested pattern inside a tuple pattern, a range index on anything but a `String`, `len` / `Int(…)` / `Float(…)` operands outside their rows, `sum(…)` / `count()` / `mean(…)` outside a closure assertion or over more than one field, `prod(…)`, a closure band that mixes `Int` and `Float`, an `@ffi` parameter with a default or of an enum, locus or interface type, `sort()` of a `@form(vec)` whose cell has no default ordering, a `@form(lru_cache)` key that is no `Int` or `String`, a literal subject's payload field the wire cannot carry, an enum in a native `shm_ring`, a `Drain<T>` handler on a `layout:` ring, and a cross-pool child whose params the spawn cannot marshal or which keeps a `run()`, subscriptions, closures, capacity slots or an `accept`. Each of these was refused by `hale build`, often with no file or line, so a program that built is unaffected, with one exception: such a construct inside a generic fn or generic locus that nothing instantiates was never compiled, so that program built and is now refused. Rewrite the construct as the diagnostic says, or delete the unused template.

### Fixed
- Shapes `hale check` accepted and `hale build` refused now compile (GH #1942): a call through the fn value any callee expression evaluates to (`pick()(2)`, `a.get()(4)`, `fs[0](4)`, `t.0(4)`, `(if c { f } else { g })(5)`); zero-length arrays (`[x; 0]`, a `[T; 0]` parameter, `let xs: [Int; 0] = [];`); any value type returned through an interface, a perspective or a fn value, a `StringView` included; a generic fn specialized at a locus, an interface, `U256`, `I256`, `Bytes` or a view type; and a compound assignment to an element of a locus's array field (`self.xs[i] += n`). `hale fmt` writes a call through a tuple's part tight, `t.0(4)`.
