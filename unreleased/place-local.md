- `hale habitat organism place|unplace <organism> <command> --host local` places a host command on the habitat's own machine, the host its rows already call `local`: on a habitat on this machine each script runs here with `sh` (sudo asks at this terminal), so a laptop with no other hosts places a native node without SSH to itself or a `host add`; through a pointer, `local` is the habitat's machine, reached over the pointer's login. The plan, inputs and secrets are the same as for any host, the placement is recorded under `local` (its readings scraped at `host.docker.internal`), and taking the habitat or the organism away takes it off the same way. A host the habitat does not hold is refused naming `--host local` beside `host add`.
