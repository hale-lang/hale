- **Fixed:** a handle a method keeps is a borrow its receiver holds, and must outlive it (GH #1048). `std::http::Router.add` keeps its handler and `use` its middleware, so a handler literal built in a function that returns the router, or fills a router it was handed, or fills `self`'s router, is refused with the rule named. Before, the router dispatched into a freed handler. Make the handler a field of the locus that owns the router, or build and use the router in one frame. The borrow rule (GH #730 and this) now runs on `build`, `run` and `test` as well as `check`.
