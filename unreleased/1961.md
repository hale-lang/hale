### Breaking
- A `bounded[T; N]` local bound from a place is a copy, not a view (decisions F.49), as a record, a String or an array already is. `let mut mine = self.row.tags; push(mine, x) or …;` no longer writes `self.row.tags`, and a later write to `self.row.tags` no longer shows through `mine`. Migration: write the place itself (`push(self.row.tags, x)`), or store the local back whole (`self.row.tags = mine;`). An intrinsic (`push`, `set`, `clear`, `truncate`) that writes a local declared with `let` is now refused at the check, so view-style code written with `let` is reported where it stops writing the place. A `bounded` field default, which lowering silently ignored, is now refused at the check.

### Added
- `bounded[T; N]` lists are values (GH #1951). An array literal at a declared `bounded[T; N]` site (a `let` with that type, a `return`, an argument, an assignment, a record literal's field) is that list, its count the literal's length; `[]` is empty, and a literal longer than `N` is a check error where it is written. A local bound from a literal or a call is owned, and a `let mut` one is assigned whole. Free fns, locus methods, modes and interface methods may return `bounded[T; N]` by value, with its String and record elements copied into the caller's arena; `count(make())` reads the result, and `push(make(), x)` is refused.
