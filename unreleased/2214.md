### Fixed

- An array-repeat literal whose element is a record, an array, a tuple or a `bounded` list, `[e; N]`, gives each element its own value. It stored one value in all N slots, so a write through one element was seen through every other: `let mut grid = [[0; 4]; 3]; grid[0][1] = 5;` set `grid[1][1]` to 5 as well, and `[P { x: 0 }; 3]` was one record. `e` is still evaluated once, and each slot holds a deep copy of it, as a struct binding is a copy. Scalar repeats such as `[0; N]` are lowered as before (GH #2211).

Breaking: a program that wrote through one element of such a repeat and read the write back through another now sees each element as its own value. `[f(); N]` still calls `f` once.
