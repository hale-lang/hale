### Fixed

- An array-repeat literal of a locus, `[L { }; N]`, builds N loci, one per element, as the longhand `[L { }, L { }, …]` does: each has its own birth, state, adoption by its owner and teardown. It built one locus and stored it in all N slots, so a write through one element was seen through every other (`[Counter { }; 3]`: bumping element 0 gave `c0=1 c1=1 c2=1`). The same holds for an element that holds a locus (`[[L { }; 2]; 3]`, a tuple with one, an array of interface values) and for a repeat a fn returns. A plain element is still evaluated once and copied (GH #2208).

Breaking: none
