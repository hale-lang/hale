### The API surface contract (GH #1417, R0)
- `spec/api.md` states the API surface contract before any transport ships: surfaces as rows (`api` blocks and `@rpc`), a contract digest over the rows with its framing given byte for byte, serve sites with authorization before enqueue and grants per role-source instance, five outcomes with fixed per-transport mappings, the request lifecycle, streams as binding rows, and the per-exposure description. The api binding section of `spec/semantics.md` stays until R4 and points here.
- The description format is a JSON Schema, `spec/api-description.schema.json`: a per-exposure description filtered for one caller, and the program-wide inventory.
- `tests/api-contract/` is the consumer handoff: the fixture program, six caller descriptions, the inventory, one recorded Unix JSON and HTTP exchange per outcome, and a digest worked by hand. The digest values are provisional until R1 states the per-type shape hash.
