### Breaking

- A range loop's variable (`for i in lo..hi`) is now an `Int` in the check, so a value of it held where another type is declared is refused: `for j in 0..2 { let s: String = j; }` built and held the count in a `String` local, and is now "let `s`: expected `String`, got `Int`". Migration: convert the count (`to_string(j)`).

### Fixed

- A range loop whose bounds are not `Int`s (`for k in 0.5..2.0`) is refused by `hale check` ("a range loop's bounds are `Int`s; this one is `Float`"), where the check passed it and the build refused it.
