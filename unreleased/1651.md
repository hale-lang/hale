- An API field with any default (an enum's, a record's, a value computed from others) may be left out of a payload and decodes to that default, as the description always said; the codecs used to refuse it `missing_field` unless the default was a literal scalar.
- A record literal written in a default (a record type's field default, a fn's or method's parameter default) that leaves out a field with no default of its own is refused by `hale check` at the literal; it used to pass the check and fail the build.
