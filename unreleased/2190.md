### Fixed

- A `.Variant` pattern's binder against a generic enum's monomorph (`.Some(x)` against a `Value<Int>`, directly, through an alias, or in a generic body) is that variant's value, an `Int` here; the check bound it `Unknown` and held it to nothing, so `let s: String = x` passed `hale check` and the build refused the program at the match. The check now refuses it at the `let` (GH #2111).
