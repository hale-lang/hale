- The api runtime's `http::Rpc` (and `mcp::Rpc`) and `unix::Rpc` transports listen through the TCP substrate: a name `std::io::tcp::stop` reaches, and an unclaimed connection is closed. `std::io::tcp::Acceptor { path }` listens on a Unix socket. A failed accept that ends one connection (out of descriptors, an aborted connection) no longer ends the listener, and stopping a Unix listener on an `async_io` pool now ends its accept.
