- The allocation survey now counts a write through a record, array or tuple parameter as living with the record's owner, no longer freed when the method returns. Such a value escapes as `param-store`, and a writer handed a record `self` holds stores as `held-store` into the locus arena, which is never recycled. A `run()` loop or bus handler that hands a writer `self.bag` is reported at the call. `--dump-alloc-summary` shows these as `store` lines.
