Breaking: none

### Fixed

- A fixed-width integer or byte type as a generic argument (`Box<U64>`, `Box<I8>`, `Box<Bytes>`) now names its monomorph in the check: a literal at such a type is checked against the argument (`let a: Box<U64> = Box { value: "x" };` is refused by `hale check` at the field, where before the check passed it and the build refused it).

### Changed

- internal: an empty literal (`[]`), a generic record's literal spelled with the template's name, and a quantity at a denomination no declaration names now carry the type their place gives them in the checker's rows; the count of values the build types without the checker falls from about 460 to about 360 over the test corpus (GH #2111).
