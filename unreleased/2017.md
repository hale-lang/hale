### Fixed

- A `match` arm's binding is typed where it is used, as any other local is: a bare binding is of the scrutinee's type, a variant's value of the variant's declared field type, a tuple pattern's part of the element's type. `let t: String = v`, with `v` bound to an `Int`, passed both `hale check` and `hale build`; the check now refuses it at `v` (GH #2016).
- A match expression's arms must all have one type, and a block arm's value is its tail (`()` when it has none). `match s { S::B(v) -> v, _ -> "s" }` and `match c { 1 -> 5, _ -> {} }` passed `hale check`, and then `hale build` refused them. The check now refuses them at the match ("match expression arms have mismatched types: `Int` vs `()`"), the same way it refuses an `if` expression's mismatched arms. An arm that `return`s or `break`s is still allowed beside the arms that give the value (GH #2016).
- A block used as a statement that ends in a call with no `;` builds as the call statement, as the spec says. `if c { println("x") }`, and a statement `match` arm `P -> { println("x") }`, passed the check and then the build refused them ("call to `println`: no … binding") (GH #2016).
- A generic body's specialization can pass a `match` arm's binding to a generic fn: `Link::Next(n) -> id(n)` over a recursive record builds. Until now the check refused it because the binding had no type (GH #2016).

### Breaking

- A program that uses a `match` arm's binding at a type other than the one the binding has is refused at the use. Such a program built until now, because the binding had no type. Migration: use the binding at its own type. Fix the annotation (`let t: Int = v`) or convert the value (`f"{v}"`). No program in this repository relied on the hole (GH #2016).
