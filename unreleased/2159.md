### Breaking

- An imported seed's enum variant (`lib::Scope::key`) is now its enum in the check, so a value of it held where another type is declared is refused: `let s: String = lib::Scope::key;` built and held the variant, and is now "let `s`: expected `String`, got `lib::Scope`". The same holds for a generic enum's variant spelled with the monomorph's name (`Value_Int::None`). Migration: declare the place with the enum's type, or convert the value (`to_string(lib::Scope::key)`).

### Changed

- internal: the count of values the build types without the checker falls from about 360 to about 300 over the test corpus (GH #2111).
