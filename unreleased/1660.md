- **`std::log` writes records by default.** `StdoutSink` and `FileSink` now write one logfmt record per event: `time=2026-10-19T06:56:00Z level=warn logger=app.db msg=retrying attempt=2`. Every level goes to stdout. `HALE_LOG_FORMAT=json` writes one JSON object per line, and `HALE_LOG_FORMAT=text` restores the previous `[WARN app.db] retrying` lines with WARN and ERROR on stderr. A sink's `format:` param pins the format in code. A line break in a logged value is written as `\n`, so each record stays on one line.
