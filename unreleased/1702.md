- DNA: integration watches. A `[dna.integrations.<name>]` table in `hale.toml` declares an upstream integration (a changelog or docs page, a releases feed, or an OpenAPI document watched through its imported surface's `hale api drift`), its owning position and cadence. The organization checks it on a schedule convened by that position: the first check is the baseline, a moved source lands an `integration.<name>.changed` reading with the unified diff as its receipt and a concern routed to the position, and three failed reads in a row land one `integration.<name>.unreachable` reading.
