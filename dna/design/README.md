# The organism, drawn

Three figures for the DNA organism as a whole: its parts, its trust
tiers, and how a change moves through its stores. They are the
reference for [the parts epic, #990](https://github.com/hale-lang/hale/issues/990)
and the part issues it links, and they describe the target state, not
what every part does today; the epic's table says which is which.

- `organism-processes-and-trust` — trust tiers as bands, the record and
  the nerves as buses, every part by name.
- `organism-one-leg` — one leg exploded: claim, hat, render, voice
  adapter, hands, token at use, settle, closure; the hands exploded
  under it.
- `organism-one-store-per-step` — two changes as chains, each step
  writing one store: a practice becoming knowledge, and a code change
  reaching the application.

Each figure is an SVG (the source) and a PNG (for embedding where SVG
does not render, such as an issue). Redraw the SVGs by hand or from the
page they were exported from; the PNGs are exports of the SVGs.
