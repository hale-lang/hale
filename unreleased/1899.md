### Added

- `hale habitat forge publish <organism> [--branch <name>] [--dry-run]` carries the main of an organism's repository at the habitat's Forgejo to GitHub as one pull request per publish: it pushes `sync/<YYYY-MM-DD>` (never forced; GitHub's `main` must be an ancestor of the internal main) and opens a pull request against `main` whose body lists the internal pull requests merged since the last publish, by title and internal number, with no links into the private forge. Publishing again the same day updates that branch and pull request. `hale habitat forge <organism> github --repo <owner/name> --publish` names where it goes (its token the vault slot `forge-token` unless `--key-vault` names another), leaving the organism's forge as allocated.
