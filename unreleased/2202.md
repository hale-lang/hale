### Changed
- A locus param typed as a record whose every field has a default may be left out of the locus literal (`params { cfg: Cfg; }` with `type Cfg { host: String = "localhost"; port: Int = 8080; }`, then `Server { }`): it is `Cfg { }`, as spec/types.md § Locus params says. `hale check` refused the literal (`missing field`) while the build supplied the default.
- internal: the build takes every value's type from the checker; a value with no checker type, or of another type than the checker's, is refused at its span as a compiler defect (GH #2111).

Breaking: none
