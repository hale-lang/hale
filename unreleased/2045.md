### Breaking
- A native `shm_ring(...)` binding (no `layout:`, no `codec(...)`) whose topic payload is not flat-shapeable (a `String`, `Bytes`, tuple, enum, list or array of records in it) is refused by `hale check` at the binding, whether or not it says `where zero_copy`. It used to build and was unsound: the ring copies the payload's bytes, so a `String` crossed as a pointer into the publisher's memory (a use-after-free in process, an empty value across processes). Migration: carry only fixed-size scalar fields (and inline scalar arrays such as `[Int; 8]`) on the ring; send variable data on a `unix(...)` binding, or as a `BytesView` raw frame on a `layout:` ring (#2030).
- A `shm_ring` name over 31 bytes, its leading `/` counted, is refused by `hale check`. macOS's shm_open refuses such a name, so the program exited at startup there; Linux opened it. Migration: shorten the name (#2030).
